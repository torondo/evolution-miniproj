# evolution-miniproj

This is the code for the Evolution module's miniproject. The project is a part of fulfilment of Imperial College London's Living Planet with Ecology, Evolution and Conservation MSc degree.

To run the code, download the folder [downloadme](https://github.com/torondo/jin-dissertation-2026/tree/main/downloadme). This contains the file `CODE.R` and all data necessary for the code to run.
